1. 隐藏的消息抽屉遮罩层拦截页面点击：为 `.drawer-backdrop` 增加 `pointer-events: none`，显示时再启用。

4. 目录末尾分节符产生空白页：删除目录后的空段落并压缩目录行距。

## 四、性能测试

JMeter 测试计划：`tools/performance/hall-test.jmx`。  
测试流程：setUp Thread Group 登录并提取 JWT → 50 个并发线程、5 秒内启动、每线程循环 20 次 → 请求 `GET /api/orders/hall?page=1&size=10` → 校验 HTTP 200。

| 指标 | 结果 |
|---|---:|
| 业务请求数 | 1 000 |
| 测试持续时间 | 4.87 s |
| 平均响应时间 | 2.89 ms |
| 最小响应时间 | 1 ms |
| P50 | 3 ms |
| P90 | 5 ms |
| P95 | 5 ms |
| P99 | 6 ms |
| 最大响应时间 | 49 ms |
| 吞吐量 | 205.34 请求/秒 |
| 错误率 | 0% |

响应时间分布：0–1 ms 64 次、2–4 ms 832 次、5–9 ms 102 次、10–19 ms 1 次、20 ms 以上 1 次。

> 说明：上述结果来自本地单机、H2 文件数据库和默认 JVM 配置，仅用于验证系统的基本性能，不代表生产环境容量。切换到 MySQL、增加连接池或部署到服务器后，应重新压测。
